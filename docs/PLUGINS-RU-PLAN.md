Проверки, которые **не подтвердились или уточнены** (важно для плана):

1. **Ядро отстаёт от установленного Harness.** `pnpm run check:harness:keys` с `DSH_HARNESS_ROOT=/tmp/harness-020rc2`
   падает: `settings-archived-sessions: Harness package @deepseek-ai/dsh-client-ui-settings-unarchive-sessions was not found`
   — в 0.2.0-rc.2 такого пакета нет (владелец namespace'а `settings.archivedSessions` удалён/переехал).
   То есть карта `scripts/harness-namespaces.mjs` описывает 0.1.6-alpha.2.
2. **Дрейф ключей подтверждён на двух крупных namespace'ах** (сверка исходников Harness 0.2.0-rc.2 с `src/client/dictionaries`):
   `chat` — 183 ключа в Harness против 101 базового в ru (**не хватает 91**);
   `conversation` — 369 против 154 (**не хватает 216**).
   По установленным бандлам картина та же; суммарная оценка «несколько сотен строк» — индикативная,
   точный список даёт обновлённый скрипт паритета (фаза 0.5).
3. **Новые namespace'ы 0.2.0-rc.2, которых нет в карте upstream**: `settings.agentLoop`, `settings.shell`,
   `settings.subagent`, `settings.webSearch` (пакеты `ui-settings-*` существуют), плюс опциональный
   `voice-input` из экспериментального bundle.
4. **Число инструментов уточнено**: tty — **18** (а не 19): `tty_*` (10), `sftp_*` (7), `tunnel_list`;
   rss — **0** инструментов (только заметка в промпте и UI), codegraph — **0**.
   Итого host-инструментов с китайскими описаниями: 22 (docker) + 18 (tty) + 5 (loglens) + 2 (mcp) = **47**.
5. **`@xbzbing/dsh-git-panel` уже русифицирован**: регистрирует `{zh, en, ja, es, fr, de, ru, pt}`,
   в `ru` 554 ключа (2 значения с китайскими символами). В наши словари не входит.
6. **Карточки плагинов** (`readPluginMeta`) читают `locale/*.json` **внутри** пакета через его `exports`
   (файлы должны резолвиться из самого пакета) — плагином-оверлеем не перекрываются.
7. **Хук для host-строк существует и официальный**: `ctx.on('system-prompt/assemble', async (assembly, ctx, next) => …)`,
   waterfall покрывает `sections`, `contexts`, `tools`, `variables`; слушатели без scope-тега — глобальные;
   возвращённое значение авторитетно (`dsh-system-prompt/lib/index.js:355`).
8. **Один владелец на (ns, locale)**: повторная регистрация пары бросает (см. типы `LocaleRuntime.register`).
9. **Плюрализации в словарях плагинов нет**: ключей `.one/.few/.many` нет, `{n}` подставляется в одну строку →
   счётные строки переводим грамматически нейтрально («Файлов: {n}»).
10. **ornith-9b** (замерено): 8 коротких ключей ≈ 5 с, JSON валиден, плейсхолдеры сохранены; нужен
    `max_tokens ≥ 4096` и явное «не рассуждай» (иначе весь бюджет уходит в `reasoning_content`); один слот llama.cpp.

## 2. Пять поверхностей «китайского» и что с ними можно сделать

| # | Поверхность | Где живёт | Механизм локализации | Перекрывается плагином? |
|---|---|---|---|---|
| 1 | UI-словари плагина | `client.js` → `ctx.locale.register(ns,'zh'/'en',dict)` | `ru` → `en` → `common` | **Да**: `register(ns,'ru',dict)` |
| 2 | Карточки «Настройки → Плагины» | `package.json.description` + `locale/*.json` пакета | `readPluginMeta` | **Нет** (файлы внутри пакета) |
| 3 | Схемы инструментов для модели | host-код: `description`, `parameters` | `system-prompt/assemble` | **Да** |
| 4 | Заметки в system prompt | host-код: секции `plugin:dsh-*` | `system-prompt/assemble` | **Да** |
| 5 | Рантайм-сообщения (ошибки, результаты) | host-код, вшитый текст | — | Частично (дорого/рискованно) |

Вывод: пункты 1, 3, 4 делаются **одним форком без форков upstream-плагинов**. Пункт 2 требует
патча установленных пакетов, пункт 5 — отдельный, дорогой и рискованный слой.

## 4. Ключевые технические находки

1. **Один владелец на (ns, locale)** → наши словари всегда новый `ru`; внешние namespace'ы регистрировать
   поштучно в `try/catch` (будущая версия плагина может сама добавить `ru`), свои 48 — строго транзакцией.
2. **Фолбэк `ru → en`** → неполный словарь показывает английский, а не сырой ключ; можно выкатывать частями.
3. **Плюрализация**: в плагинах нет `.one/.few/.many` → нейтральные счётные конструкции.
4. **git-panel** уже с `ru` → не трогаем (можно отдельно почистить 2 значения с CJK).
5. **Host-хук** `system-prompt/assemble` → описания инструментов, параметры и секции промпта без форков upstream.
6. **Карточки плагинов** → только файлами внутри пакета (скрипт-патч) или форками upstream.
7. **Лицензии**: `@hyzyn/*` Apache-2.0 (производный перевод → attribution/NOTICE, отметить изменения);
   остальные MIT; upstream локализации MIT.
8. **ornith-9b**: годится для коротких UI-строк (батчи 8–12, валидация JSON/плейсхолдеров); длинные тексты,
   счётные строки и host-инструкции — основная модель.
9. **Ядро 0.1.0 устарело относительно 0.2.0-rc.2** (см. §0): без обновления ядра UI остаётся частично
   английским независимо от плагинов → отдельная фаза 0.5.
10. **Дрейф ключей** при обновлении Harness/плагинов — штатная ситуация: нужны снимки, тест паритета и
    политика «непереведённое — оставляем оригинал + warning».

## 5. Упаковка (решено)

Форк **как оригинал**: то же имя пакета `@absolutemikhail/dsh-locale-ru`, тот же формат bundle-пакета,
drop-in замена. В профиле меняется только источник:

```json
"@absolutemikhail/dsh-locale-ru": "github:URfinJus72/dsh-locale-ru"
```

Нельзя ставить одновременно с upstream — обе регистрируют язык `ru` (конфликт `addLanguage`).
Публикация в npm под чужим scope невозможна; установка — через git (собранные `lib/` в репозитории).
